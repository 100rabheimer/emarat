# 🏢 EMARAT Landing Page

A modern real-estate landing page inspired by the **EMARAT** website design.

This project was built from scratch to practice frontend development fundamentals, with a focus on creating a clean luxury-style interface using semantic HTML and modern CSS.

## ✨ What We Built

The landing page currently includes:

* Transparent navigation bar over the hero section
* EMARAT branding/logo
* Responsive full-screen hero image
* Hero content overlay
* Active navigation state
* Navigation hover effects
* Golden **Enquiry Now** CTA
* Golden **Explore Projects** CTA
* Hero image dark overlay for better readability
* Custom typography and spacing
* Smooth button hover animation

## 🎯 Purpose of This Project

The main purpose of this project is to strengthen frontend fundamentals by **building instead of only studying theory**.

The project helped practice how to break a website design into smaller UI sections and convert those sections into HTML and CSS.

The development process followed:

**Observe → Structure → Style → Test → Debug → Improve**
